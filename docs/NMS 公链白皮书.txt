## 1. 项目愿景

NMS MetaLife 旨在构建一个「消费即分红、共同富裕」的 Web3 生活生态。通过 RWA 实物资产代币化，将线下商家、实物商品、门店股权上链为可流通、可分红、可版税分成的 NFT；通过 AI 量化引擎与自动风控熔断保障跨链资产安全；通过 P2P 端对端社交与 DAO 治理实现去中心化协作。

核心目标：
- **消费即铸造**：用户消费即获得 1:1 NMS 积分并铸造 NFT，享受永久版税与分红。
- **RWA 确权**：实物资产经法律公证 + 多签委员会审核 + DOI 存证，生成可分享的链上 VC 凭证。
- **AI 风控**：Minara-AI 全网监控流动性异常，自动触发智能合约熔断，将资产从高风险矿池撤回安全池。
- **P2P 社交**：基于 Hyperswarm/Holepunch 的端对端加密社交，DID 身份 + Kyber-768 量子签名。

## 2. 公链技术架构

### 2.1 四层区块链架构

```
┌─────────────────────────────────────────────┐
│  L4 应用层  (DApps / 商家 / 钱包 / 社交)      │
├─────────────────────────────────────────────┤
│  L3 协议层  (RWA确权 / NFT / AI风控 / DAO)    │
├─────────────────────────────────────────────┤
│  L2 共识层  (PoS+AI 验证 / 多签委员会)         │
├─────────────────────────────────────────────┤
│  L1 网络层  (P2P Hyperswarm / Kyber-768)      │
└─────────────────────────────────────────────┘
```

| 层级 | 职责 | 关键技术 |
|------|------|----------|
| L1 网络层 | 节点发现、消息广播、端对端加密 | Hyperswarm DHT、Hypercore append-only log、Kyber-768 量子签名 |
| L2 共识层 | 区块验证、交易排序、多签审核 | PoS + AI 辅助验证、多签委员会（3/5 签名）、0 Gas 机制 |
| L3 协议层 | 业务协议实现 | RWA 确权合约、NFT1155/721、AI 风控熔断合约、DAO 治理合约 |
| L4 应用层 | 用户交互 | React + Tailwind 前端、Base44 BaaS 后端 |

### 2.2 共识机制

- **PoS + AI 验证**：节点质押 NMS 参与出块，Minara-AI 实时评估节点行为，异常节点自动降权。
- **多签委员会**：RWA 确权、大额跨链调度等关键操作需 3/5 多签委员会审核通过。
- **0 Gas 机制**：交易 Gas 费由平台补贴，用户零手续费，通过量子签名（Kyber-768）保障安全。

### 2.3 量子安全

- **Kyber-768**：抗量子计算的密钥封装机制（KEM），用于钱包公钥与交易签名。
- **Dilithium**：抗量子数字签名算法，用于合约签名验证。
- 所有链上交易携带 `quantum_signature` 与 `signature_time_ms` 字段（见 Transaction 实体）。

### 2.4 Minara-AI 框架

Minara-AI 是贯穿全链的 AI 中枢：
- **风控监控**：实时扫描全网流动性、矿池风险、跨链桥状态。
- **策略生成**：量化策略自动生成、回测、进化优化。
- **合规审核**：RWA 上架前的 AI 合规评分（0-100）。
- **智能客服**：AI 管家、AI 投顾、语音助手。

## 4. RWA 实物确权流程

商家上架商品 NFT 统一走 **5 步 RWA 流程**（见 `RWANFTListingModal` 组件）：

```
Step1 基本信息 → Step2 图片上传 → Step3 RWA确权 → Step4 版税设置 → Step5 确认上链
```

### 4.1 流程详解

1. **基本信息**：商品名称、描述、类别、资产类型（实物商品/门店股权/服务权益/不动产权）、单价、发行数量、打赏比例、门店分红率。
2. **图片上传**：商品图片作为 NFT 链上元数据，支持预览。
3. **RWA 确权**：
   - 上传法律公证文件（营业执照/公证书/产权证明），生成链上哈希存证。
   - **AI 合规审核**：调用 `InvokeLLM` 生成合规评分（0-100）、是否通过、风险点、建议。
   - 生成 **DOI 存证**（全球唯一标识符）。
   - 多签委员会审核（48h 内，3/5 签名）。
   - 颁发 **VC 凭证**（可验证凭证，可在元 Social 中分享）。
4. **版税设置**：商家/推荐人/节点 NFT 持有者/平台四方版税分配（每次二次转售自动触发）。
5. **确认上链**：自动冻结保证金（单价×数量×10%），一键发布上链。

### 4.2 链上公证多签流程

```
商家提交 → DOI存证生成 → AI合规评分 → 多签委员会(3/5) → 颁发VC凭证 → 商城上架
```

### 4.3 VC 凭证

已确权资产生成专属可分享的链上资产证书（Verifiable Credential），包含：
- 资产元数据哈希
- DOI 标识符
- 多签签名列表
- AI 合规评分
- 颁发时间与有效期

## 5. NFT 生态体系

### 5.1 NFT 类型

| 类型 | 说明 | 分红机制 |
|------|------|----------|
| 实物 NFT | 消费铸造，50% 分红 + 50% 预留门店 NFT | 永久版税 10% |
| 门店 NFT | 门店股权，50% 分红 + 50% 预留节点 NFT | 月度营业额分红 |
| 节点 NFT | 全网算力参与挖矿 + 治理权 | 超额分红 25% |
| 个人 NFT | 创作者数字资产 | 版税永续分配 |

### 5.2 版税四方分配

每次 NFT 二次转售，智能合约自动按比例分配版税：
- 商家 2.5% · 推荐人 2.5% · 节点 NFT 持有者 2.5% · 平台 2.5%（可调，总 10%）

### 5.3 NFT 合成

9×9×9 矩阵合成系统：2 张同店 NFT + 1 张合成通宝 → 更高等级 NFT，提升分红率与释放加速。

### 5.4 二级市场与跨链

- 二级市场：NFT 自由交易，版税自动结算。
- 跨链流动池：NFT 跨链流转，LayerZero 桥接。

## 6. AI 量化与风险自动熔断

### 6.1 AI 量化引擎

- **策略类型**：套利、流动性挖矿、做市、趋势跟踪、情绪分析。
- **策略工作室**：AI 生成策略（Vibe 模板）+ 参数调优 + 回测 + 进化优化 + 多智能体模拟。
- **跨链调度**：自动平衡多链资产，跨链收益农场。

### 6.2 风险自动熔断（AICircuitBreaker）

当 Minara-AI 监控到以下异常时，自动触发智能合约熔断：

| 触发条件 | 阈值 | 动作 |
|----------|------|------|
| 全网流动性异常波动 | 波动率 > 25% | 暂停所有跨链调度 |
| 单矿池资产风险加剧 | 风险评分 > 75 | 从高风险矿池撤回至安全池 |
| 智能合约异常 | 审计告警 | 冻结相关资产 |
| 跨链桥延迟 | 确认 > 30min | 暂停桥接通道 |

**熔断流程**：
```
Minara-AI 监控 → 风险评分计算 → 触发阈值 → 智能合约自动执行 → 资产撤回安全池 → 用户风险通知
```

支持自动/手动两种模式，可配置规则阈值。

### 6.3 资产监控中心

多维资产监控：跨链桥状态、RWA 资产、量子合约安全、AI 风控、合约审计五位一体。

## 12. 个人发布NFT与消费凭证（V8.0新增）

### 12.1 个人发布NFT（闲鱼模式）

个人用户可像闲鱼一样拍照发布NFT，流程：拍照/上传 → AI识别商品信息 → 填写表单 → **NMS锁定** → 上链。

**NMS锁定机制（提升使用率与经济闭环）**：
- 发布个人NFT需锁定发行总价 **25%~45%** 的 NMS（用户可调滑块）。
- 锁定NMS随NFT交易逐步释放，提升NMS流通与使用率。
- NFT享永久 10% 二次转售版税。

```
NFT总价 = 单价 × 发行数量
锁定NMS = NFT总价 × 锁定比例(25-45%)
```

### 12.2 消费凭证上链（链商宝模式）

用户上传真实消费小票/凭证，AI OCR 识别消费总额，**销毁 25%~45% NMS** 即可获得 **1:1 消费返还 NMS**。

流程：上传凭证 → AI识别总额 → 选择销毁比例 → 销毁NMS → 1:1返还到账。

```
消费总额 = AI识别(元)
销毁NMS = 消费总额 × 销毁比例(25-45%)
返还NMS = 消费总额 × 1.0  (1:1)
```

**经济意义**：销毁机制通缩NMS，1:1返还激励真实消费上链，形成「消费→凭证→销毁→返还」的高效闭环。

### 12.3 商家发行机制（对照）

商家发行实物NFT走5步RWA确权流程（见第4章），自动冻结保证金10%。个人发布走简化流程+NMS锁定，两者互补构成完整NFT发行生态。

// src/hooks/useReferral.js — 全局唯一推荐码生成入口

## 20. Web4.0 Agentic钱包架构

### 20.1 设计理念

NMS MetaLife 钱包升级为 Web4.0 Agentic 钱包，核心理念：

- **AI + ZK 框架**：零知识证明(Kyber-768 KEM)保障交易隐私，AI Agent 在不暴露私钥的前提下自主执行策略。
- **自托管多链**：用户保留全部私钥控制权，支持 NMS Chain / Ethereum / Polygon / BNB Chain 多链资产管理。
- **Agent 一等公民**：Minara AI Agent 作为一等公民（而非附属功能），可编程地与去中心化环境交互——套利、复投、跨链再平衡，但不可转移资产。

### 20.2 安全模型

```
用户私钥(本地) → ZK证明生成 → Agent策略执行 → 链上验证 → 资产控制权(人类)
```

- 私钥永不离开本地设备
- Agent 仅获得"可编程交互权"，无资产转移权
- 所有关键操作需 ZK 证明 + 用户授权

### 20.3 Agent 能力矩阵

| 能力 | 说明 | 安全约束 |
|------|------|----------|
| 自主套利 | AI Agent 自动扫描跨链价差，在最优路径执行交易 | 单笔上限10%余额，ZK验证 |
| 风控熔断 | ZK 证明实时验证交易安全性，异常自动拦截 | 链上3秒更新 |
| 自动复投 | 收益自动再投入最优流动性池 | 仅限白名单池 |
| 跨链调度 | 多链资产自动再平衡，维持最优配置 | 需多签确认 |
